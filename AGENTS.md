# AGENTS.md

## Repository Purpose

LLM learning notes repository - documentation only, no executable code.

## Directory Structure

- `inference/` - Inference optimization techniques (KV cache, speculative decoding, etc.)
- `compression/` - Model compression methods (quantization, pruning, etc.)
- `training/` - Training-related topics
- `application/` - LLM applications

## Documentation Conventions

- Language: Chinese
- Style: Detailed technical explanations with formulas, examples, and code snippets
- Format: Markdown with tables, code blocks, and mathematical notation

## Notes

- This is a knowledge base for LLM concepts, not a code repository
- Files are standalone technical deep-dives on specific topics
- Empty directories are placeholders for future content
